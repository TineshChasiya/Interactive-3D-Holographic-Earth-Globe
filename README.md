# 🌍 Interactive 3D Holographic Earth Globe

A futuristic Interactive 3D Holographic Earth Globe built using HTML5 Canvas, CSS3, and Vanilla JavaScript.

## ✨ Features

- Interactive 3D holographic globe
- Click and drag to rotate
- Scroll to zoom
- Touch support
- Animated star background
- Latitude and longitude grid
- Neon cyan holographic glow
- Automatic rotation
- Smooth animation
- Responsive canvas
- No external libraries

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 Canvas API
- requestAnimationFrame()

## 📂 Project Structure

Interactive-3D-Holographic-Earth-Globe/
├── index.html
├── style.css
└── script.js

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. The holographic globe will start automatically.

## 🎮 Controls

- Mouse Click + Drag — Rotate the globe
- Mouse Wheel — Zoom in / Zoom out
- Touch Drag — Rotate the globe
- Idle Mode — Automatic rotation

## 🎨 Design

The project uses a futuristic holographic HUD design with a dark space background, cyan neon glow, circular scanning rings, grid lines, and animated stars.

## ⚙️ JavaScript Features

- 3D point projection
- X and Y axis rotation
- Depth-based transparency
- Mouse interaction
- Touch interaction
- Zoom control
- Responsive canvas scaling
- Smooth animation
- Radial glow effects
- Starfield rendering

## 📱 Responsive Design

The canvas automatically adjusts according to the browser window size and supports both desktop and mobile touch interaction.
